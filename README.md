# Norsk hver dag

一个针对中文母语 A2 学习者的手机友好挪威语训练网页。无需构建工具。

## 运行

在项目目录执行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。Chrome/Edge 支持口语识别时可使用 `Snakke` 页面。

## 判题方式

- 选择题、填空题：标准化大小写、空格和结尾标点后精确匹配。
- 自由造句：本地规则检查目标结构、情态动词后的原形、`har + 完成分词`、V2 语序与已知固定搭配。
- 本地规则不能可靠判断复杂语义和自然度，因此会明确提示人工或 AI 复核，而不是误判为绝对正确。
- 错题保存在浏览器 `localStorage`，并按语法技能分类。

后续可增加服务端 `/api/evaluate`，让语言模型输出结构化 JSON，并继续把确定性语法规则作为第一层检查。
