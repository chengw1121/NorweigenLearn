# Norsk hver dag

题库、译文覆盖、句子分析、错题间隔复习与词汇进度检查：在项目根目录运行 `node tests/question-integrity.test.mjs`。该检查覆盖动词题型、专题题库、阅读文章、核心词汇上下文例句、固定搭配译文、随机整套练习、到期错题自动入练、句子成分拆解和词汇进度统计。

答题反馈优先显示完整句的中文译文，并对可识别的基础句型提供主语、限定动词、时间状语、动词补语等成分拆解。句型分析只标出规则能确认的成分；复杂结构仍以专题或阅读中的逐句语法说明为准。固定搭配例句逐条配有句意译文。

一个针对中文母语 A2 学习者的手机友好挪威语训练网页。无需构建工具。

词汇覆盖进度在完成主动回忆卡后增加；“已掌握”另按连续回忆正确次数统计。错题首次安排到挪威当地次日复习，答对后依次拉开到 3、7、14、30 天；到期错题会自动替换当日新题的一部分，连续通过 3 次间隔复习后退出待复习队列。

学习页的常用词汇主题中包含“未来与人生计划”专题词池；词汇练习与完整课程从同一张主题卡进入。`Tema: fremtid`课程含8节语法、82个带情境插画符号和挪威语例句的跨词类词卡、原课本对话与阅读双语逐段朗读、16道自动判分题及8项写作迁移。专题词可以与其他主题重复，重复词按各自情境练习；专题词卡可直接进入统一主动回忆和进度追踪，阅读词汇可收藏后立即练习或加入混合复习。开放式写作使用自检清单，不冒充AI评分。错题页保留原句和中文句意，答对后按间隔复习逐渐退出待复习队列。

当前学习路径包括：

- 按5/10/15/20/30题选择每日训练量，并自动分配四形、情态、过去、完成、`å + V1`、固定搭配、改错和V2语序；
- 65个手册动词参考条目、46个名词；八个专题背词池目前去重后为92个词条（46动词、46名词）；
- `Lær`专题主动回忆：动词/名词交替练习；名词记冠词和词形变化，动词记四形；带挪威语内嵌键盘、主题句、中文翻译、浏览器本地朗读；
- 词卡中的词头、动词变化、名词词形都可单独播放；发音使用设备上可用的挪威语语音；
- 名词卡给出精确义项和易混词提示，所有词卡例句显示中文翻译；小屏幕上“下一项”固定在内嵌键盘之前；
- 按回忆结果安排间隔复习（次日、3天、1周及更长间隔）；
- 每道题的中文意思、完整正确句、规则、动词四形和记忆动作。
- “未来与人生计划”作为常用词汇主题之一，保留五种未来表达、V2语序、时态回顾、专题词汇、课本对话与阅读的完整课程；专题词可与其他主题重复，并按该专题语境单独记录掌握度。
- 错题集支持遮住答案重新输入、查看提示和解释；复习答对后会从待复习列表移除。

自动训练暂不包含需要AI才能可靠判断的开放式作文或口语评分题。专题写作任务提供保存草稿和自检清单。

## 账号、排行榜和奖牌

邮箱注册、邮箱验证、登录和密码重置由 Supabase Auth 托管；Cloudflare Worker 通过 Supabase Auth 校验 access token，D1 只保存公开昵称、积分事件和奖牌，不存邮箱或密码。不要把 Supabase `service_role` 密钥放进网页或 Worker；本项目只需要 Project URL 和 publishable/anon key。

“我的”分为概览、奖牌、排行榜和练习偏好。奖牌集中在一个陈列室：已点亮的在前，只显示积分、连续学习、当月和当年的下一步里程碑；节日与生肖作为隐藏款，不提前列出，达成后会弹出解锁庆祝。圣诞与新年各保留一个年度纪念款；旧账号中历史重复奖牌会在界面合并显示，不删除数据库记录。节日奖牌要求当天在服务端累计至少 10 学习积分。连续目标为 3/7/30/90/180/365/730/1,095 天；每个自然月达到 20 个有效学习日获得月牌；每个自然年达到 120/180/240 个有效学习日获得三个年度等级。有效学习日按挪威当地日历日计算，当天服务端累计至少 10 学习积分才算，单纯登录不计；历史进度直接从积分事件计算，因此升级不需要额外运行 D1 migration。

排行榜和奖牌目前用于学习激励，不是反作弊系统：积分在服务端计分并有每日上限，但浏览器端学习事件仍可能被伪造，不要用它发放有现金价值的奖励。可删除 D1 学习积分，但 Supabase Auth 账号删除需在 Supabase 控制台管理（当前界面不提供误删风险较高的账号删除按钮）。

### 首次部署到 Cloudflare Workers + D1

先在 Supabase 创建项目，在 Authentication → URL Configuration 中把 Site URL 设为你的站点（例如 `https://norweigenlearn.chengw1121.workers.dev`），并把该站点和本地测试地址 `http://localhost:4173/**` 加入 Redirect URLs。Authentication → Providers 中启用 Email，并保持邮箱确认开启。Supabase 内置邮件发送有严格的试用速率限制（目前默认每小时2封），适合小规模验证流程；公开邀请更多人之前需配置自有 SMTP，并检查邮件模板中的确认/重置链接。

在 Supabase 项目 API/Connect 页面取得 Project URL 和 publishable key（旧项目也可能显示 anon key）。然后在本地项目目录运行：

```powershell
npx wrangler d1 create norweigenlearn
```

把命令返回的数据库 ID 填入 `wrangler.jsonc` 的 `database_id`，然后配置 Worker 变量（这两项是公开客户端标识，不是 service-role 密钥）：

```jsonc
"vars": {
  "SUPABASE_URL": "https://你的项目编号.supabase.co",
  "SUPABASE_ANON_KEY": "你的 publishable 或 anon key"
}
```

接着创建远端表并部署静态站点与 Worker：

```powershell
npx wrangler d1 migrations apply norweigenlearn --remote
npx wrangler deploy
```

Cloudflare 端不需要 Resend 密钥，也不保存用户密码。注册用户须先点击 Supabase 邮件验证链接；若 Workers Free 不满足当前运行需求，再评估套餐，不要在未确认前升级付费方案。每个真实环境只运行一次 D1 migration；修改已应用的 schema 时应新增 migration，不要改写已执行的迁移。

本地仅运行 `python -m http.server` 时，账号接口不会工作；需用 `npx wrangler dev --remote` 测试 Worker/D1/Supabase 联通，并确保 `wrangler.jsonc` 已配置数据库 ID 与 Supabase 变量。不要把真实密钥提交到 Git。

## 运行

在项目目录执行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。题目反馈中的“播放发音”使用浏览器本地的挪威语语音合成。

## 手动推送到 GitHub

在 PowerShell 中进入项目目录，运行：

```powershell
.\push-to-github.ps1
```

脚本会检查当前分支和 `origin`，暂存工作区改动、显示待提交文件并要求你确认；确认后才会创建提交并推送到当前分支。可传入提交说明：

```powershell
.\push-to-github.ps1 -CommitMessage "校对挪威语句子与翻译"
```

输入其他内容会取消提交/推送，已暂存的改动仍留在本地。

## 判题方式

- 选择题、填空题：标准化大小写、空格和结尾标点后精确匹配。
- 训练题使用确定性规则和标准答案，允许同一句的多种自然语序，例如 `I morgen skal jeg jobbe` 与 `Jeg skal jobbe i morgen`。
- 当前训练暂不放入需要AI才能可靠判断的开放式答案；未来可单独增加AI复核层。
- 错题保存在浏览器 `localStorage`，并按语法技能分类。

后续可增加服务端 `/api/evaluate`，让语言模型输出结构化 JSON，并继续把确定性语法规则作为第一层检查。
